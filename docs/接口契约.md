# 泠弦智谱 —— 软件线 ↔ 模型线 接口契约 v1.0

> 项目：泠弦智谱（古琴减字谱智能打谱系统） 版本：v1.0.0 更新日期：2026-09-21 适用范围：FastAPI 后端 / Vue3 前端 / 模型线（视觉模型 + 句读模型）/ 汉语言句读组 效力：本文档为跨组协作的唯一权威接口约定。任何接口变更必须先改本文档并同步各方，禁止私自改字段名、类型、语义。

## 通用约定

### 1.1 服务与端口

| 项           | 值                                             |
| ------------ | ---------------------------------------------- |
| 后端框架     | FastAPI + Uvicorn                              |
| 后端地址     | http://127.0.0.1:8001                          |
| 前端开发地址 | http://127.0.0.1:5173（Vite 代理 /api → 8001） |
| API 在线文档 | http://127.0.0.1:8001/docs                     |
| 跨域         | 仅允许 5173 端口来源                           |

### 1.2 响应统一格式

成功：

```
{ "success": true, "data": { ... } }
```

失败（HTTP 4xx/5xx）：

```
{ "detail": "错误描述" }
```

### 1.3 路径原则

- 后端代码内**全部相对路径**，禁止写死盘符（如 D:\）。

- 所有上传文件经 temp_upload/ 临时存放，处理后可清理。

- 模型权重放 backend/models/，不进 Git，走 GitHub Release。

### 1.4 标识约定

- 减字标识一律用**拼音编码 key**（如 da_9_gou_4、san_tiao_7），中文仅作显示。

- 拼音 key 必须与 backend/data/class_registry.csv 的 class_key 列完全一致，模型线不得自造类别。

## 数据结构定义

### 2.1 演奏状态 z_i（语义层输出）

每个减字解析后的结构化演奏信息，是句读模型的输入之一。

```
{
  "char_key": "da_9_gou_4",
  "display": "大九勾四",
  "type": "按音",
  "left_hand": { "finger": "大指", "string": 4, "hui": 9 },
  "right_hand": { "finger": "勾", "finger_name": "中指", "string": 4 },
  "is_san": false,
  "is_fan": false
}
```

| 字段              | 类型     | 说明                        |
| ----------------- | -------- | --------------------------- |
| char_key          | str      | 拼音编码，主键              |
| display           | str      | 中文显示名                  |
| type              | str      | 散音 / 按音 / 泛音          |
| left_hand.string  | int/null | 左手按弦（散音为 null）     |
| left_hand.hui     | int/null | 徽位（散音为 null）         |
| right_hand.finger | str      | 右手指法（勾/挑/抹/剔/撮…） |
| right_hand.string | int/str  | 右手弹弦（撮音为 "6+7"）    |

### 2.2 状态转移特征 Δz_i（数学建模层输出）

相邻两个减字 z_{i-1} → z_i 之间的数值特征向量，由 modules/state_transfer/feature_extractor.py 计算。

| 特征                 | 类型       | 说明                         |
| -------------------- | ---------- | ---------------------------- |
| string_changed       | int(0/1)   | 是否换弦                     |
| hui_delta            | float      | 徽位变化量（绝对值）         |
| left_finger_changed  | int(0/1)   | 左手指法是否变化             |
| right_finger_changed | int(0/1)   | 右手指法是否变化             |
| action_continuity    | float[0,1] | 动作连续性（越高越倾向连续） |
| position_unchanged   | int(0/1)   | 音位是否未变                 |

### 2.3 句读启发特征 q_i（汉语言句读组输出）

由 modules/judou/ 根据《句读规则手册》计算。

| 特征                 | 类型       | 说明                                   |
| -------------------- | ---------- | -------------------------------------- |
| context_completeness | float[0,1] | 当前演奏结构完整度                     |
| boundary_marker      | float[0,1] | 附近是否存在边界提示性指法/结构        |
| local_symmetric      | float[0,1] | 前后并列/对称关系                      |
| ambiguity            | float[0,1] | 该位置的专业歧义程度（多种打谱均合理） |

### 2.4 边界标签 C / S / L / E / U

标记**两个相邻减字之间**的停顿位置，而非减字本身。

| 标签 | 含义          | 说明                                   |
| ---- | ------------- | -------------------------------------- |
| C    | Continue 连续 | 不建议停顿，演奏连贯                   |
| S    | Short 短停    | 弱边界，非句末小停顿                   |
| L    | Long 长停     | 强边界，非句末大停顿                   |
| E    | End 句末      | 完整谱乐句结束                         |
| U    | Review 复核   | 非音乐标签；置信度低或专业歧义，转人工 |

**概率硬约束**（decision.py 必须校验）： P(E) ≤ P(S) + P(L) + P(E)，即句末概率不得大于"任意边界概率"，防止"不是边界却判为句末"的矛盾。

U 的两种来源（论文中需区分，产品上都显示"建议人工判断"）：

- U_m：模型置信度不足（max P < τ）

- U_a：专业歧义（q_i.ambiguity 超阈值）

## 单减字识别接口

### 3.1 上传图片识别

POST /api/char/predict

请求：multipart/form-data，字段 file（PNG/JPG/JPEG/BMP/WEBP）。

响应：

```
{
  "success": true,
  "data": {
    "candidates": [
      { "class_key": "da_9_gou_4", "confidence": 0.82 },
      { "class_key": "san_tiao_7", "confidence": 0.11 },
      { "class_key": "gou_5", "confidence": 0.04 }
    ],
    "top_key": "da_9_gou_4",
    "top_confidence": 0.82,
    "parse_result": { "char_key": "da_9_gou_4", "display": "大九勾四", "type": "按音", "...": "..." }
  }
}
```

| 字段                | 说明                                      |
| ------------------- | ----------------------------------------- |
| data.candidates     | Top-3，每项 {class_key, confidence}       |
| data.top_key        | 首选拼音 key                              |
| data.top_confidence | 首选置信度 0~1                            |
| data.parse_result   | 首选完整语义解析（查知识库，结构同 z_i）  |

> V1 为假模型兜底，候选固定；真权重到位后仅替换 classifier.predict_crop，本接口结构不动。

| GET  | /api/knowledge/library?char_type=按音 | 知识库列表，可按类型筛选       |

## 整谱打谱接口

| 方法 | 路径              | 说明                                                              |
| ---- | ----------------- | ----------------------------------------------------------------- |
| POST | /api/sheet/upload | 上传整谱，规则检测画框→逐框裁剪识别解析，返回 image_url 与 items   |
| POST | /api/sheet/correct | 人工修正回流（index/box/confirmed_key），V1 返回记录回执          |

> V1 流程：上传落盘 static/upload → detector 规则画框 → 逐框裁剪 → classifier Top-3 → parser 解析 → 置信度<0.6 标 U。
> V2 升级：detector 内部替换为 D-FINE/RF-DETR 检测模型，接口与前端不动。

## 智能句读接口（新增，核心）

### 6.1 逐句切分

POST /api/judou/segment

请求体（JSON）：

```
{
  "chars": ["gou_3", "da_9_gou_4", "tiao_7", "san_tiao_7"]
}
```

| 字段  | 类型      | 说明                                   |
| ----- | --------- | -------------------------------------- |
| chars | list[str] | 有序减字拼音 key（按竖排右起顺序排列） |

响应：

```
{
  "success": true,
  "data": {
    "count": 4,
    "segments": [
      { "index": 0, "class_key": "gou_3",      "label": "C", "confidence": 0.85 },
      { "index": 1, "class_key": "da_9_gou_4", "label": "C", "confidence": 0.85 },
      { "index": 2, "class_key": "tiao_7",     "label": "C", "confidence": 0.85 },
      { "index": 3, "class_key": "san_tiao_7", "label": "E", "confidence": 0.78 }
    ]
  }
}
```

| 字段          | 说明                                                     |
| ------------- | -------------------------------------------------------- |
| data.count    | 输入减字总数                                             |
| data.segments | 逐字边界判定，每项 {index, class_key, label, confidence} |
| label         | C/S/L/E；置信度<0.6 时为 U                               |
| confidence    | 该判定置信度                                             |

> V1 为规则假模型（8字句末/4字短停/其余连续）；modules 算法层就绪后仅替换 segment 内部，接口结构不动。

### 6.2 人工修正回流

句读结果的人工修正当前随整谱审核统一走 `POST /api/sheet/correct`（payload 含 index、box、confirmed_key）。

> 后续独立句读页上线后，可在 judou.py 新增 /review 接口；修正记录入 SQLite、不进 Git，供模型迭代。

## 模型接缝：唯一替换点

### 7.1 视觉单字分类器

文件：backend/service/classifier.py

```
def predict(self, image_path: str, top_k: int = 3) -> list[dict]:
    """
    输入：单张减字图片路径
    输出：[
      {"label": "da_9_gou_4", "confidence": 0.92, "display": "大九勾四"},
      ...
    ]
    """
```

- 这是软件线与视觉模型线的**唯一接缝**。接口签名、返回格式由软件线锁定。

- 假模型阶段返回固定候选；真模型到位后**仅替换本函数内部**，路由/前端/语义解析层不动。

### 7.2 句读模型接缝

| 文件                                        | 函数/类                                | 职责                             |
| ------------------------------------------- | -------------------------------------- | -------------------------------- |
| modules/state_transfer/feature_extractor.py | extract(seq: list[dict]) -> list[list] | 由 z_i 序列算 Δz                 |
| modules/state_transfer/baseline_model.py    | predict(features) -> list[probs]       | 可解释 Baseline（Logistic/规则） |
| modules/judou/features.py                   | build(seq, dz) -> list[list]           | 计算 q_i                         |
| modules/sequence/fusion.py                  | fuse(zi, dzi, qi) -> tensor            | 拼接特征                         |
| modules/sequence/transformer_model.py       | predict(seq) -> list[probs]            | 输出 P(C/S/L/E)                  |
| modules/sequence/decision.py                | decide(probs, qi) -> label             | 阈值 + 约束 + U 判定             |

> 句读模型线交付权重后，仅替换 transformer_model.py 与 baseline_model.py 内部实现；fusion、decision、接口、前端均不动。

## 类别主表 class_registry.csv

软件线与模型线共用的**唯一类别主表**，双方不得各自维护一份。

```
class_key,label_cn,type,description,active
da_9_gou_4,大九勾四,按音,大指九徽勾四弦,1
san_tiao_7,散挑七,散音,右手食指挑七弦散音,1
```

| 列        | 说明                                     |
| --------- | ---------------------------------------- |
| class_key | 拼音编码，主键，模型训练标签必须与此一致 |
| label_cn  | 中文显示名                               |
| type      | 散音/按音/泛音                           |
| active    | 1 启用 / 0 停用                          |

新增类别流程：先更新本表 → 双方确认 → 模型线再训练。禁止模型线自行新增类别。

## 错误码约定

| HTTP | 含义                    | 处理                      |
| ---- | ----------------------- | ------------------------- |
| 400  | 文件类型不支持/参数缺失 | 前端提示用户              |
| 404  | 减字 key 未命中知识库   | 前端允许手动输入          |
| 422  | 请求体格式不符          | 接口契约问题，开发期修复  |
| 500  | 模型推理/服务内部错误   | 返回 detail，日志记录堆栈 |
