【五大功能与识别三级降级】
  功能：①单减字识别 ②整谱打谱 ③人工修正 ④知识库 ⑤智能句读
  识别降级（任一级失败自动落到下一级，前端标签显示来源 yolo/qwen/fake）：
    一级 YOLO 本地权重 best.pt（service/yolo_infer.py，CPU 推理，需 pip install ultralytics）
    二级 阿里云多模态 qwen3-omni-flash（service/qwen_adapter.py，读环境变量
         DASHSCOPE_API_KEY，免费额度用完即停；HTTP403/401/429 自动熔断；urllib 零依赖；
         图片发送前压缩至长边960/JPEG；qwen3.8-omni-flash 偏慢仅留备选，qwen-mt-uni 为翻译模型不可用）
    三级 内置假数据（固定候选/规则句读），保证无网络、无权重时仍可演示
  识别引擎手动切换（前端单字页/整谱页可选，表单字段 engine）：
    auto 自动：YOLO 出框，能对上25类基础key的框用本地，其余框自动补多模态认字
    yolo 本地模型：仅本地、不联网不耗额度；对不上的细类框置空并标 U（显示模型初判）
    qwen 多模态：YOLO 负责出框、逐框裁剪交多模态认字（当前最准，耗额度，整谱较慢）
    注：best.pt 实测为 279 类细粒度中文标签（含弦/徽/指法，非25类基础key），
        检测框可用（XWC.png 出38框），但分类因训练样本不足、当前对不上基础key，
        故 V1 以「YOLO出框 + 多模态认字」为准；单框也可点「多模态重认」。
  整谱：各引擎均优先 YOLO 出框；YOLO 不可用则 OpenCV 规则出框（detector）后逐框分类
  人工修正：/api/sheet/correct → correction_store.py 落库 data/corrections.json
【C/S/L/E/U 边界标签】（标记两个相邻减字之间的停顿）
  C Continue  连续   —— 不建议停顿，演奏连贯
  S Short     短停   —— 弱边界，非句末小停顿
  L Long      长停   —— 强边界，非句末大停顿
  E End       句末   —— 完整谱乐句结束
  U Review    复核   —— 非音乐标签；置信度低或存在专业歧义时转人工
  约束：P(E) ≤ P(S)+P(L)+P(E)，保证"不是边界却判为句末"的逻辑矛盾不出现
【三层技术架构】
  第一层 演奏语义层：减字 → parser → 演奏状态 z_i（左手/右手/弦/徽/散按泛）
  第二层 结构句读层：
        古琴知识 → state_transfer/feature_extractor → 状态转移 Δz_i
        汉语言句读 → judou/rules+features → 句读启发特征 q_i
  第三层 序列推断层：fusion 拼接 [z_i, Δz_i, q_i] → sequence/transformer_model → P(C/S/L/E)
                    → decision 按阈值与约束输出标签，低置信/歧义 → U
  注：V1 句读直接用多模态 qwen3-omni-flash 输出 C/S/L/E；modules/ 内算法为 V2 预留空壳
【双模型对照（消融实验，写论文用）】
  Baseline：baseline_model.py 仅用 Δz_i，可解释、易复现
  序列模型：transformer_model.py 用 [z_i, Δz_i, q_i] 学习上下文
  两者对比：证明领域特征与序列建模各自贡献，无论谁高都可成结论
【模型可插拔原则】
  yolo_infer / classifier.predict_crop / qwen_adapter / baseline_model / transformer_model
  均为独立替换点，上层接口、decision、前端不动，仅替换内部实现即可切换模型
【视觉与乐理分离原则】
  视觉模型只认字形（输出拼音 class_key）
  乐理全部交给 jianzipu_lib.json（左手弦/徽 + 右手指法 + 释义）
  class_registry.csv 为软件与模型共用的唯一类别主表
【上传约定】
  支持 .png / .jpg / .jpeg；后端扩展名白名单 + UUID 重命名 + PIL 校验，防中文路径问题

【启动命令】
  后端（首次需先装 YOLO 依赖）：
        conda activate lingxian
        pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
        pip install ultralytics          # 不装也能跑，会自动降级到多模态/假数据
        cd backend
        python main.py
  前端：cd frontend
        npm install
        npm run dev
  多模态密钥（PowerShell 当前用户永久生效）：
        [Environment]::SetEnvironmentVariable("DASHSCOPE_API_KEY","你的key","User")
