============================================================
  关键说明
============================================================

【两阶段本地推理（无外网云API、无假数据兜底）】
  Stage1 YOLO best.pt：检测减字位置框，竖排右起排序；模型仅1类，不负责分类。
  Stage2 多头ResNet18 stage2_best.pth：对每个裁剪框输出8个属性头
        （rh/string/lh/hui_base/hui_frac/mod/tone/strings），
        取前5头拼 key，经 parser 归一化后查 jianzipu_lib.json 得中文释义。
  模型未就绪 / 权重缺失：接口直接返回 503/500，提示联系开发人员，不返回假数据。

【类别主表 class_registry.csv，178 类】
  category 分布：single 23、modifier_only 1、compound 1、
        散音 13、按音 44、泛音 43、装饰音 11、复合音 42。
  软件线与模型线共用唯一主表，class_key 拼音编码，中文仅作显示，禁止自造类别。

【C/S/L/E/U 句读标签】（标记相邻减字之间的停顿）
  C 连续 / S 短停 / L 长停 / E 句末 / U 人工复核。
  V1 用 judou.py 本地规则（复合长指法→E，走手修饰音→S，8字/4字兜底）；
  modules 算法与训练权重为 V2 预留。

【日志与反馈路径（统一 backend/utils/logs/）】
  mlnlog.log：运行日志，*.log 不进 Git；文件为 UTF-8，
        PowerShell 查看用 Get-Content -Encoding UTF8，避免中文乱码。
  feedback.txt：人工修正反馈，保留 Git 跟踪。

【权重转存】
  权重不进 Git，通过网盘 / U盘 / 本地拷贝等方式在团队间转存更新，
  放入 backend/models/ 即可被自动加载，无需改代码。

【端口与启动】
  后端 FastAPI http://127.0.0.1:8001 （API文档 /docs）
  前端 Vite    http://127.0.0.1:5173
  后端：conda activate lingxian && cd backend && python main.py
  前端：cd frontend && npm install && npm run dev
